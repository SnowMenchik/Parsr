# 📊 Parser

Многофункциональный парсер количества просмотров для постов из **VK**, **Telegram** и **OK.ru**.  
Поддерживает пакетную обработку ссылок из файла, автоматическое сохранение результатов и удобное управление учётными данными через конфигурационный файл.

## ✨ Возможности

- **VK** – получение просмотров через официальный API (метод `wall.getById`).
- **Telegram** – сбор статистики через MTProto-клиент Telethon (прямое подключение к серверам Telegram).
- **OK.ru** – гибридный подход: парсинг HTML + необязательное использование OK API (если указаны ключи).
- **Гибкая конфигурация** – все токены и настройки хранятся в `config.json`.
- **Пакетная обработка** – достаточно поместить ссылки в `links.txt`.
- **Сохранение результатов** – детальный отчёт в формате JSON (`results.json` и `results_<дата>.json`).

🔑 Получение API-ключей
VK
Перейдите на vkhost.github.io или используйте официальный способ получения токена.

Выберите приложение (например, VK Admin) и разрешите доступ к стене (wall).

Скопируйте токен из адресной строки или поля ответа.

При первом запуске программа запросит токен и сохранит его в config.json.

Telegram
Авторизуйтесь на my.telegram.org.

Перейдите в раздел API Development Tools.

Создайте приложение (можно указать любое название).

Запишите API ID и API Hash.

При первом запуске введите эти данные и номер телефона (в формате +79123456789).
После успешной авторизации создаётся файл сессии telegram_session.session – повторный вход не потребуется.

OK.ru
API-ключи не обязательны. Скрипт автоматически парсит HTML страницы.

Если вы хотите повысить точность, зарегистрируйте приложение на apiok.ru, получите Application Key, Session Secret Key и Application ID и укажите их по запросу программы.

🚀 Использование
Создайте (или отредактируйте) файл links.txt и поместите в него ссылки на посты (по одной на строку).
Поддерживаются ссылки вида:

https://vk.com/wall-123456_7890

https://t.me/channelname/1234

https://ok.ru/groupname/topic/123456789012345

и многие другие форматы.

Запустите парсер:

bash
python parser.py
Следуйте инструкциям в консоли:

Если учётные данные ещё не сохранены, программа предложит их ввести.

Для Telegram потребуется ввести код подтверждения (при первом запуске) и, возможно, облачный пароль, если включена двухфакторная аутентификация.

После обработки в консоль будет выведено суммарное количество просмотров и сохранены файлы:

results.json – всегда содержит последний результат.

results_ГГГГММДД_ЧЧММСС.json – детальный отчёт с временной меткой.

⚠️ Важные замечания
Telegram требует аккаунта, не используйте ботов — скрипт подключается как обычный пользователь.

При обработке большого числа Telegram-постов учитывайте лимиты: Telethon автоматически ожидает при FloodWaitError.

OK.ru может блокировать частые запросы, поэтому между запросами установлена задержка. Если просмотры не определяются, попробуйте указать API-ключи.
